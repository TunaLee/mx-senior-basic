## 사용 방법

### 1. NotebookLM에 자료 업로드

1. notebooklm.google.com 접속 (Google 계정 로그인)
2. *Create new notebook* 클릭
3. *Add sources* 클릭
4. 3개 파일 모두 드래그 앤 드롭 (Markdown 지원)
5. 분석 대기 (수십 초)

### 2. 추천 실습 질문 (시니어 실무 시나리오)

#### 단일 자료 질문 — *기본*
- (자료 01) 사용자가 가장 불만 갖는 기능 3가지는?
- (자료 01) 60대 이상 사용자의 핵심 니즈는?
- (자료 02) Apple Intelligence와 Galaxy AI의 차이는?
- (자료 02) 2026년 모바일 AI 시장 성장률은?
- (자료 03) Q1 2026 매출 목표와 결과는?
- (자료 03) AI Agent 개발 우선순위는 왜 1순위가 됐나?

#### 자료 간 비교 질문 — *심화*
- 사용자 피드백(자료 01)과 시장 분석(자료 02)을 종합해, 우리가 우선 개선해야 할 기능 3가지는?
- 회의록(자료 03)에서 결정된 AI Agent 개발이 시장(자료 02)의 어떤 트렌드와 맞물리나?
- 시니어 시장 진입 전략(자료 03)을 사용자 피드백(자료 01)이 뒷받침하는 근거는?

#### 종합 분석 질문 — *실무*
- 세 자료를 종합해 *임원 보고용 1페이지 요약*을 작성해줘. 형식: 현황·핵심·인사이트·시사점·제언.
- 다음 분기 우선 투자해야 할 *3가지 영역*과 그 근거를 자료에서 인용해줘.
- *부정적 피드백*과 *경쟁사 동향*을 매핑해 *대응 우선순위*를 표로 정리해줘.

### 3. Audio Overview (팟캐스트) 활용

NotebookLM 우측 패널의 **Audio Overview** 클릭 → *Generate* 누르면:
- 두 명의 AI 호스트가 *팟캐스트처럼 자료 요약 대화* 생성
- 약 8~12분 분량
- 실무자가 *출퇴근 시간에 듣기 좋은* 형식

→ 시니어 청중이 시각 자료 외 *음성으로 정리* 받는 새로운 경험 체감.

## 워크샵 진행 팁

### 권장 흐름 (Part 5 실습 약 30분)

1. **5분** — NotebookLM 가입·접속 + 자료 3개 업로드
2. **5분** — 기본 질문으로 RAG 답변 체감 ("자료 안에서만 답한다")
3. **10분** — 자료 간 비교 질문 — 출처 표기 확인
4. **5분** — 종합 분석 — 임원 보고용 1페이지 메모 생성
5. **5분** — Audio Overview 생성 → 일부 청취

### 핵심 학습 포인트
- *RAG의 위력* — 환각 없이 자료 기반 답변
- *출처 인용* — 어디서 나온 정보인지 즉시 확인
- *교차 참조* — 여러 자료를 동시에 분석
- *Audio Overview* — 자료를 *팟캐스트로* 변환
